# MacroBook iOS

MacroBook is an iOS calorie and macronutrient tracking app designed to make daily food and activity logging simple, organized, and fully customizable.

## Features

- **Food Intake Logging**
  - Record meals and food intake
  - Track calories, protein, carbohydrates, and fat
  - Set serving amounts
  - Add notes to individual logs

- **Activity Logging**
  - Record physical activities
  - Track calories burned
  - Add notes and timestamps

- **Daily Tracking**
  - View daily calorie intake and activity
  - Monitor calorie targets
  - Calculate daily calorie balance

- **History**
  - Browse logs by date
  - View daily summaries
  - Track calorie deficit or surplus
  - View weekly and monthly calorie balance
  - Search previous logs

- **Log Management**
  - View detailed information for each log
  - Edit existing intake and activity logs
  - Delete logs

## Tech Stack

- **Language:** Swift
- **UI:** SwiftUI
- **Architecture:** MVVM
- **Database:** Core Data
- **IDE:** Xcode
